Взаимодействие с сервером через curl

Сервер поддерживает следующие API-команды (файловый менеджер):

  • Получить список файлов
    curl http://localhost:8080/files
  • Загрузить файл
    curl -X POST -d "содержимое" http://localhost:8080/upload
    (файл сохранится в www/uploads/upload_<timestamp>.dat)
  • Загрузить бинарный файл
    curl --data-binary "@myfile.jpg" http://localhost:8080/upload
  • Удалить файл
    curl -X DELETE "http://localhost:8080/delete?file=uploads/upload_123.dat"

Все команды возвращают JSON-ответ.
